# 12FZ Chat 统一用户身份方案（修订版）

## 一、系统全景

```
┌─────────────────────────────────────────────────────────┐
│  go.12fz.com  (12FZ 智能中台 — 大一统平台)               │
│  数据库: 12fzsj                                          │
│  用户表: public.org_user  ← 唯一用户源头                  │
│  主键:   user_id SERIAL                                   │
│  当前用户: 1=admin, 2=测试用户                            │
└──────────────┬──────────────────────────────────────────┘
               │
               │  chat 系统直接引用 org_user.user_id
               ▼
┌─────────────────────────────────────────────────────────┐
│  ai.12fz.com  (Chat 服务)                                │
│  数据库: aichat                                          │
│  不再维护独立的 users 表                                   │
│  所有用户字段 = FK → 12fzsj.public.org_user.user_id       │
└─────────────────────────────────────────────────────────┘
```

## 二、aichat 数据库改造

### 2.1 删除的表

```sql
DROP TABLE IF EXISTS chat.users CASCADE;
DROP TABLE IF EXISTS chat.agents CASCADE;
```

### 2.2 新建表（跨库引用 org_user）

```sql
-- Agent 专有配置
CREATE TABLE chat.agent_configs (
    user_id        INTEGER PRIMARY KEY,  -- = org_user.user_id
    model          VARCHAR(64) DEFAULT 'tk.12fz.com',
    system_prompt  TEXT,
    capabilities   TEXT[] DEFAULT '{}',
    api_key        VARCHAR(256),
    api_url        VARCHAR(256),
    created_at     TIMESTAMPTZ DEFAULT now(),
    updated_at     TIMESTAMPTZ DEFAULT now()
);

-- 多登录方式（扩展 org_user，支持手机/微信）
CREATE TABLE chat.login_credentials (
    id         SERIAL PRIMARY KEY,
    user_id    INTEGER NOT NULL,           -- = org_user.user_id
    provider   VARCHAR(16) NOT NULL,       -- 'password' | 'phone' | 'wechat' | 'email'
    identifier VARCHAR(128),               -- 手机号 / 微信openid / 邮箱
    credential VARCHAR(256),
    created_at TIMESTAMPTZ DEFAULT now()
);
CREATE INDEX idx_login_user ON chat.login_credentials(user_id);
```

### 2.3 现有表字段类型变更（全部改为 FK → org_user.user_id）

```sql
-- friends: text → integer
ALTER TABLE chat.friends ALTER COLUMN user_id   TYPE INTEGER USING user_id::INTEGER;
ALTER TABLE chat.friends ALTER COLUMN friend_id TYPE INTEGER USING friend_id::INTEGER;

-- friend_messages: text → integer
ALTER TABLE chat.friend_messages ALTER COLUMN from_id TYPE INTEGER USING from_id::INTEGER;
ALTER TABLE chat.friend_messages ALTER COLUMN to_id   TYPE INTEGER USING to_id::INTEGER;

-- messages: text → integer
ALTER TABLE chat.messages ALTER COLUMN sender_id TYPE INTEGER USING sender_id::INTEGER;

-- group_members: bot_id → user_id, text → integer
ALTER TABLE chat.group_members RENAME COLUMN bot_id TO user_id;
ALTER TABLE chat.group_members ALTER COLUMN user_id TYPE INTEGER USING user_id::INTEGER;

-- groups: text → integer
ALTER TABLE chat.groups ALTER COLUMN created_by TYPE INTEGER USING created_by::INTEGER;

-- bot_statuses: bot_id → user_id, text → integer
ALTER TABLE chat.bot_statuses RENAME COLUMN bot_id TO user_id;
ALTER TABLE chat.bot_statuses ALTER COLUMN user_id TYPE INTEGER USING user_id::INTEGER;
```

## 三、数据迁移（关键）

当前 `aichat` 中的数据需要映射到 `12fzsj.org_user.user_id`：

```
aichat 旧值                  →   12fzsj.org_user.user_id
────────────────────────────────────────────────────
users.id=1, username='admin'  →   user_id=1 (admin)
users.id=2, username='gong3'  →   user_id=2 (测试用户)  ← 需确认
agents.bot_id='chaogu-ai'     →   新建 org_user (user_id=3, nickname='chaogu-ai')
agents.bot_id='gong3'         →   user_id=2
agents.bot_id='服务器技术'     →   新建 org_user (user_id=4, nickname='服务器技术')
agents.bot_id='高级工程师'     →   新建 org_user (user_id=5, nickname='高级工程师')
```

迁移脚本：
```sql
-- Step 1: 在 12fzsj 中为 Agent 注册 org_user
INSERT INTO 12fzsj.public.org_user (nickname, status)
VALUES ('chaogu-ai', 'active'), ('服务器技术', 'active'), ('高级工程师', 'active')
RETURNING user_id;
-- 假设返回: 3, 4, 5

-- Step 2: 更新 aichat.friends（当前 user_id/friend_id 是 string）
UPDATE chat.friends 
SET user_id = CASE user_id::text 
  WHEN 'admin' THEN '1' WHEN 'gong3' THEN '2' WHEN '1' THEN '1' ELSE user_id::text END;

-- Step 3: 同理更新 friends_messages, messages, group_members, groups

-- Step 4: 迁移 agent 配置
INSERT INTO chat.agent_configs (user_id, model, system_prompt, capabilities)
SELECT 
  CASE bot_id 
    WHEN 'chaogu-ai' THEN 3 
    WHEN '服务器技术' THEN 4 
    WHEN '高级工程师' THEN 5 
    ELSE 2 
  END,
  model, system_prompt, capabilities
FROM chat.agents;
```

## 四、登录凭据处理

`org_user` 目前密码字段在表内（`password` + `salt`）。保留不动，同时新建 `login_credentials`：

```sql
INSERT INTO chat.login_credentials (user_id, provider, identifier, credential)
SELECT user_id, 'password', phone, password FROM 12fzsj.public.org_user
WHERE password IS NOT NULL;
```

未来新增手机/微信登录只插 `login_credentials`，不动 `org_user`。

## 五、后端代码改动

| 模块 | 改动 |
|------|------|
| auth.go | login() 查询 `org_user` 验证密码，返回 `user_id`（int64） |
| auth.go | session token `session-{N}` → 直接 parseInt 得到 user_id |
| http.go | `getBotID(r)` → `getUserID(r)` 返回 `int64` |
| db.go | 所有 user 参数 string → int64；需要 username 时 JOIN `org_user` |
| model.go | `BotID string` → `UserID int64`，JSON tag 改为 `user_id` |
| whoami API | `GET /api/whoami` → 查询 org_user 返回 `{user_id, nickname, phone}` |

---

## 六、前端代码改动

| 模块 | 当前 | 改为 |
|------|------|------|
| auth.ts | `botId = "admin"` (string) | `userId = 1` (number) |
| auth.ts session 处理 | `token.slice(8)` | `parseInt(token.slice(8))` |
| chat.ts | `sender_id: string` | `sender_id: number` |
| 所有展示用户名 | 直接显示 `bot_id` | 调 `/api/users/:id` 取 nickname |
| localStorage key | `bot_id` | `user_id` |

## 七、执行步骤

```
1. 停 chat 服务
2. pg_dump aichat → 备份
3. 在 12fzsj 中为 Agent 创建 org_user 记录
4. UPDATE aichat 所有表：string ID → integer（映射到 org_user.user_id）
5. ALTER TABLE 改字段类型
6. 创建 agent_configs、login_credentials 并迁移数据
7. DROP chat.users, chat.agents
8. 部署新后端代码（读写 org_user）
9. 部署新前端代码
10. 启动服务
```
